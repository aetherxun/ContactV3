# 通讯录 V3（链表版）

一个用标准 C 写的命令行通讯录，用来练手**单向链表 + 文件读写 + 多文件编译**。
纯学习项目，无第三方依赖，在 Windows / MSVC 下构建。

## 快速开始

1. **怎么编**：双击 `build.bat`（需 VS2026 +「使用 C++ 的桌面开发」工作负载），生成 `ContactsV3.exe`；或在 VS2026 里新建空项目、添加三个源文件后按 `Ctrl+F5`。
2. **怎么跑**：在命令行执行 `ContactsV3.exe`，按菜单数字操作，选 `0` 保存并退出；也可用 [`冒烟验收.md`](冒烟验收.md) 的 5 条逐条验收。
3. **文件在哪**：存档 `contacts.txt` 生成在**当前工作目录** —— VS 里是项目目录，命令行里是 exe 所在目录，请固定一种启动方式，否则会误以为数据丢了。

> `build.bat` 不是源码，只是一张写好的命令行纸条：找到 VS、配好编译器路径，再执行 `cl /W4 main.c contact.c` 生成 exe。它的职责到生成 exe 为止。

## 文件结构

| 文件 | 作用 |
|------|------|
| `contact.h` | 类型定义与函数声明（带头文件保护） |
| `contact.c` | 链表增删查、存档 / 读档 |
| `main.c` | 菜单与程序入口 |
| `build.bat` | 一键调用 MSVC 编译 |
| `冒烟验收.md` | 5 条最短验收路径 + 复盘模板 |
| `.gitignore` | 声明哪些文件不进版本库 |

## 实现要点

- 单向链表尾插，用文件私有的 `static` 变量保存头指针与人数
- `malloc` / `free` 成对，退出前由 `free_all()` 统一释放
- `fgets` 逐行读取 + `sscanf` 解析，坏行自动跳过，不会带崩整个文件
- 三个源文件各自编译，再由链接器合成一个 exe

## 清理与重建

删除 `*.obj` 与 `ContactsV3.exe`，再跑一次 `build.bat` 即可从零重建。
编译产物和 `contacts.txt` 都已在 `.gitignore` 中忽略，不会进版本库。
